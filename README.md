# 🚚 DeliveryMetrics Pro

Dashboard responsivo de análise operacional de entregas, desenvolvido como projeto de portfólio por **Luan Márcio Alvarenga de Arruda**.

## ✨ Funcionalidades

- **KPIs:** pedidos no período, taxa de entregas no prazo, tempo médio e receita estimada
- **Gráficos:** volume diário de pedidos e distribuição por status
- **Filtros:** período de 7, 14 ou 30 dias e status da entrega
- **Pesquisa:** busca por código do pedido ou cliente
- **Insights locais:** análises automáticas **baseadas em regras**
- **Metas operacionais:** barras de progresso e comparativo com objetivos
- **Exportação CSV:** download de registros filtrados
- **Interface responsiva:** visual dark para desktop e dispositivos móveis

## 🛠️ Tecnologias

HTML5 · CSS3 · JavaScript (Vanilla JS)

Sem dependências, instalação de pacotes, autenticação ou necessidade de chave de API.

## ▶️ Como executar

1. Baixe o repositório em **Code → Download ZIP**.
2. Extraia os arquivos.
3. Abra `index.html` no navegador.

Também é possível usar o **Live Server** do VS Code.

## 📁 Estrutura

```text
deliverymetrics-pro/
├── index.html    # Estrutura e componentes da página
├── styles.css    # Identidade visual e responsividade
├── app.js        # Dados, cálculos, filtros e exportação
└── README.md     # Documentação
```

## 🧪 Testes manuais sugeridos

- Alterar os filtros de período e status e conferir a atualização dos indicadores
- Pesquisar por nome ou código do pedido
- Limpar filtros
- Exportar CSV e abrir em um editor de planilhas
- Conferir o comportamento em diferentes tamanhos de tela

## ⚠️ Escopo demonstrativo

Os **120 pedidos são fictícios e gerados localmente** para fins de demonstração. Não há banco de dados, backend ou acesso a dados reais de plataformas de entrega. Os insights utilizam regras de negócio, **não inteligência artificial generativa**.
